Capture

万物皆可记一笔

英语素材散落在世界的每个角落。语学伴把它们收进一个 App——随手一扔，Agent 自动识别、整理、入库。

社交媒体截图

教材与 PDF

大学英语、剑桥雅思等各版本教材 PDF，整本解析，词汇、例句、长难句逐条转为学习资产。

音频与视频

网页与文章

粘贴链接即可全文入库，外刊、博客、论文里的地道用法一个都不漏。

Workflow

三步，从碎片到体系

采集 → 闪卡 → 聚合。Agent 负责所有繁琐的事，你只管学。

1

随手采集

截图、上传、粘贴链接。任何格式的英语素材，扔进语学伴就自动记一笔。

2

统一为闪卡

所有资产被 Agent 拆解、规范化为 flashcard 碎片，附带语境、来源与难度标签。

3

聚合为学习内容

Agent 根据你的目标重新聚合碎片：应试的生成机考真题，听说的泛化成对话练习。
